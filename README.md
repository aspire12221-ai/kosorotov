# Городской чат-бот (Urban GPT Assistant)

Чат-бот для сферы управления городским хозяйством, работающий на базе **OpenAI GPT-3.5 Turbo**.  
Помогает жителям и специалистам разбираться в вопросах ЖКХ, транспорта, благоустройства, экологии и тарифов.

## Возможности

- 🤖 Ответы на естественном языке с использованием большой языковой модели.
- 🏙️ Тематическая ориентация: городское хозяйство, инфраструктура, аварийные службы.
- 💾 Локальное хранение API-ключа (только в вашем браузере).
- 🧹 Очистка истории диалога.
- 📱 Адаптивный интерфейс (работает на мобильных устройствах).
- 🔐 Ключ никогда не передаётся на сторонние серверы, кроме официального API OpenAI.

## Как запустить

1. **Склонируйте репозиторий** или скачайте файл `index.html`.
2. Откройте `index.html` в любом современном браузере (Chrome, Edge, Firefox, Safari).
3. **Получите API-ключ** OpenAI:
   - Зарегистрируйтесь на [OpenAI Platform](https://platform.openai.com/).
   - Перейдите в раздел API Keys → создайте новый ключ (начинается с `sk-...`).
   - Пополните баланс (для работы GPT-3.5 Turbo требуется небольшой платёж).
4. В правом верхнем углу чата введите ключ и нажмите кнопку 💾.
5. Начните диалог! Можно задавать вопросы вручную или использовать готовые примеры.

## Размещение на GitHub Pages

1. Загрузите содержимое репозитория (файлы `index.html`, `README.md`, `LICENSE`, `.gitignore`).
2. В настройках репозитория включите **GitHub Pages** (ветка `main`, папка `/`).
3. Чат-бот станет доступен по адресу `https://ваш-username.github.io/urban-chatbot/`.

> ⚠️ **Важно**: API-ключ вводится **лично вами** и сохраняется в `localStorage` браузера. Никто, включая GitHub, не имеет к нему доступа.

## Ограничения

- Для работы требуется **действительный API-ключ OpenAI** с ненулевым балансом.
- Бесплатные пробные ключи OpenAI имеют лимиты, для активного использования рекомендуется пополнить счёт.
- История диалога ограничена 20 последними сообщениями для экономии токенов.
