# Умный дашборд городского хозяйства Москвы

Интерактивный дашборд для мониторинга ключевых показателей ЖКХ, благоустройства и работы городских служб Москвы.  
**Не требует ввода API-ключей** — работает полностью автономно в демонстрационном режиме с имитацией AI-советника на основе данных дашборда.

## 🚀 Функциональность

- Визуализация динамики заявок в Жилищник, удовлетворённости граждан и расходов бюджета
- Ключевые показатели (открытые заявки, время ответа, количество дворников)
- Чат с AI-советником (без внешних вызовов, на основе данных дашборда)
- Генерация аналитического отчёта с рекомендациями

## 🔧 Использование

1. Откройте `index.html` в любом современном браузере (локально или через GitHub Pages).
2. Дашборд готов к работе — никаких ключей вводить не нужно.
3. Задавайте вопросы в чате или нажимайте «Сгенерировать отчёт».
